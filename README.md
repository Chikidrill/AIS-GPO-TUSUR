# АИС «ГПО ТУСУР»

Автоматизированная информационная система для организации группового проектного обучения в ТУСУР.

Система предназначена для работы студентов, преподавателей и администраторов с проектами ГПО, заявками на участие и составом проектных команд.

## Возможности

### Студент

- просмотр каталога проектов;
- поиск и фильтрация проектов;
- просмотр подробной информации о проекте;
- подача заявки на участие;
- просмотр своих заявок;
- отзыв активной заявки;
- просмотр статуса заявки.

### Преподаватель

Функциональность находится в разработке.

Планируется:

- просмотр своих проектов;
- просмотр участников проектов;
- работа с результатами и работами студентов.

### Администратор

- просмотр и фильтрация проектов;
- создание проектов;
- редактирование проектов;
- удаление проектов;
- изменение статуса проекта;
- назначение и смена преподавателя;
- просмотр заявок студентов;
- принятие и отклонение заявок;
- просмотр участников проектов.

## Роли

В системе предусмотрены три роли:

- `STUDENT` — студент;
- `TEACHER` — преподаватель;
- `ADMIN` — администратор.

Доступ к страницам и действиям разграничивается в зависимости от роли пользователя.
